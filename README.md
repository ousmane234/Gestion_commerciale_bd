# Gestion commerciale – V1 (catégories et produits)
Flask + MySQL (FreeDB) + Bootstrap, déployé sur Render.

Variables d'environnement requises (Render > Environment) :
DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME, SECRET_KEY

Commande de build : `pip install -r requirements.txt`
Commande de démarrage : `gunicorn app:app`
